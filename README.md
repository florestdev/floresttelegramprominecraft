## ✅ Возможности

- Двусторонний чат Minecraft ↔ Telegram
- Команды из Telegram с выводом результата
- TPS / RAM мониторинг
- Фото → карты в игре
- Реакции на сообщения
- Достижения / вход / выход
- LuckPerms префиксы
- PlaceholderAPI поддержка
- Полная кастомизация сообщений

## 📦 Установка

1. Скачай `FlorestTelegramPRO.jar`
2. Помести в `plugins/`
3. Перезапусти сервер
4. Настрой `config.yml` (токен бота + ID чата)

---

## 🔧 Команды

| Команда | Права |
|---------|-------|
| `/ftp reload` | `floresttelegram.admin` |
| `/ftp close / open` | `floresttelegram.admin` |
| `/ftp ban / unban <id>` | `floresttelegram.admin` |
| `/ftp mute / unmute <id>` | `floresttelegram.admin` |

### Команды из Telegram

- `/players` — список игроков
- `/tps` — TPS + RAM
- `/<команда>` — выполнить в консоли

## ⚙️ Режимы работы

| Режим | Сложность |
|-------|-----------|
| `polling` | Простой (по умолчанию) |
| `webhook` | Для профи (HTTPS + публичный IP) |
